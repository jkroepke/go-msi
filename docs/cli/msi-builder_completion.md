# `msi-builder completion`

Print a shell completion script

Completion prints the script that completes msi-builder commands, flags,
file arguments, signature digests and, for inspect --table, the tables of
the package on the command line. Each shell has its own command.

## Usage

```text
msi-builder completion [command]
```

## Flags

```text
  -h, --help   help for completion
```
