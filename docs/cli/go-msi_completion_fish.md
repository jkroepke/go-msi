# `go-msi completion fish`

Print the completion script for fish

Prints the completion script for fish.

Load it in the current shell with:

    go-msi completion fish | source

or install it for every new shell:

    go-msi completion fish > ~/.config/fish/completions/go-msi.fish

## Usage

```text
go-msi completion fish [flags]
```

## Flags

```text
  -h, --help              help for fish
      --no-descriptions   leave out the descriptions of the completions
```
